# 🎓 StudentMS — Система управления успеваемостью студентов

Веб-приложение для управления данными студентов, учёта посещаемости и успеваемости.  
Создано как готовое решение для образовательных учреждений, репетиторских центров и курсов.  
**Работает полностью на стороне клиента** — данные сохраняются в браузере пользователя.

## 🚀 Демонстрация

👉 Попробовать вживую: **[Демо на Netlify](https://hilarious-starburst-aa2f8f.netlify.app/)**  
*(Замените ссылку на актуальный URL вашего деплоя)*

## ✨ Возможности

- **👥 Управление студентами** — добавление, редактирование, удаление записей (имя, номер зачётной книжки, факультет, курс)
- **🔍 Поиск и фильтрация** — быстрый поиск по имени, факультету, ID или номеру зачётки
- **📋 Учёт посещаемости** — отметки присутствия, отсутствия или опозданий с привязкой к дате
- **📝 Оценки по предметам** — добавление любых предметов с балльной системой (1–100)
- **📊 Автоматический расчёт** — средний балл и процент посещаемости для каждого студента
- **📈 Дашборд** — ключевые метрики: всего студентов, средний балл, средняя посещаемость, количество факультетов
- **📥 Экспорт в CSV** — скачивание полного отчёта со всеми данными для дальнейшей обработки
- **💾 Локальное хранилище** — вся информация сохраняется в `localStorage`, не требует сервера
- **🖥️ Адаптивный интерфейс** — одинаково удобно на десктопе и планшете

## 🧩 Структура интерфейса

- **Дашборд** — сводка и последние добавленные студенты
- **Студенты** — полный список, CRUD‑операции и поиск
- **Посещаемость** — журнал посещений с фильтрами
- **Успеваемость** — все выставленные оценки
- **Экспорт** — генерация и скачивание CSV‑отчёта

## 🛠️ Технологии

- HTML5, CSS3 (кастомный дизайн, Flexbox/Grid)
- Чистый JavaScript (ES6+), без фреймворков
- `localStorage` для хранения данных
- Адаптивная вёрстка под мобильные устройства
- Готовность к размещению на любом статическом хостинге (Netlify, GitHub Pages и др.)
